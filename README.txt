PaceMeter — Chrome / Edge / Brave Browser Extension (Manifest V3)
==================================================================

100% Local Processing:
- Measures speaking pace (WPM) locally on your laptop using Web Audio API
  syllable-onset DSP + optional Web Speech API.
- Zero external API calls, zero audio recording, zero cloud dependencies.

Your Pre-Configured Defaults:
- Minimum Optimal Pace: 115 WPM
- High-Speed Alert Threshold: 168 WPM
- Sustain Before Alert: 3 seconds
- Gentle Headphone Chime: Enabled
- Overlay Position: top-right (standard)

How to Install on Your Laptop (30 seconds):
1. Unzip this folder somewhere permanent (e.g. ~/Documents/pacemeter-extension).
2. Open Chrome, Edge, or Brave and navigate to:
   - Chrome: chrome://extensions
   - Edge:   edge://extensions
   - Brave:  brave://extensions
3. Turn ON "Developer mode" in the top-right corner.
4. Click "Load unpacked" and select the unzipped folder containing manifest.json.

How to Use in an Online Lecture:
- Open Google Meet, Zoom Web, Microsoft Teams, or Webex — the floating PaceMeter
  HUD appears automatically (or click the PaceMeter toolbar icon / press Alt+Shift+P
  on any tab).
- Drag the HUD bar to position it neatly near your webcam lens so students never
  see you looking away.
